# Mizan — a Moroccan-law chatbot with an animated character

A chatbot that answers questions about Moroccan law **from the official texts only**, cites the exact article, and links to the official PDF page. It comes as a small widget you can drop into any website, with an animated Lottie character ("Mizan") that thinks, talks, smiles or refuses.

> Chatbot kayfhem l9anoun lmeghribi, kay3tik l'article li staned 3lih w lien dyal source officielle, w fih character animé. Code kamel: Angular + Python.

- **Frontend:** Angular, packaged as a Web Component (`<mizan-chat>`) with Shadow DOM, plus a lottie-web character (one state per Lottie segment).
- **Backend:** Python + FastAPI, streamed answers (SSE) from Gemini Flash, with fallbacks when a model is busy.
- **RAG:** the official PDFs (Code du travail, Code de la famille, Constitution) are split into articles (1170 passages) and stored in PostgreSQL + pgvector. Search is hybrid: vectors (multilingual-e5-large, local) plus Postgres full-text, fused with RRF. The question is first rewritten into French legal keywords.
- **Security:** the API key stays on the server, input validation, rate limiting (per minute and per day), a prompt-injection filter, a canary token that stops the answer if instructions leak, and only the sources the answer actually cites are returned. If nothing relevant is found, it says so instead of inventing an answer.

## Run it locally

You need Python 3.10+, Node 20+, and a free Gemini API key from https://aistudio.google.com/apikey

```bash
# 1. backend
cd backend
python -m venv .venv
.venv\Scripts\activate          # Windows  (macOS/Linux: source .venv/bin/activate)
pip install -r requirements.txt
copy .env.example .env          # then paste your GEMINI_API_KEY in .env
python download_docs.py         # the 3 official PDFs -> data/raw
python ingest.py --fresh        # split into articles + embeddings -> Postgres
uvicorn app.main:app --port 8000
```

No Postgres install needed: with `DATABASE_URL` empty, the backend starts an embedded Postgres (pgserver) in `backend/pgdata`. On Windows, run `start_db.ps1` once before starting the API. To use your own Postgres, set `DATABASE_URL` (it needs the `vector` extension).

```bash
# 2. widget
cd widget
npm install
npm start                       # http://localhost:4200
```

## Put it on any website

Build the widget (`npm run build`), host the files from `widget/dist`, then add:

```html
<script src="main.js" type="module"></script>
<mizan-chat api="https://your-api.example.com" mascot="mizan.json"></mizan-chat>
```

Set `ALLOWED_ORIGINS` in `backend/.env` to that website's address.

## Use it for something else

Nothing here is specific to law except the documents and the prompt. Swap the PDFs in `backend/ingest.py` and the instructions in `backend/app/prompts.py` and you get a chatbot for e-commerce, customer support, a school, or any field where you have documents.

## Notes

- Answers are information from the official texts, not legal advice.
- The texts come from adala.justice.gov.ma (Code du travail 2011, Code de la famille, Constitution 2011).
- The character is generated by `widget/tools/build_mascot.py` into `widget/public/mizan.json`.
